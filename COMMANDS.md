# ALife Worlds commands

In a local Codex chat, type `@commands`, select **commands** under **Skills**, and send the message to see the ALife Worlds menu. For an individual workflow, type its search text below, select the skill with the matching ALife Worlds description, then send your request. If the picker is unavailable, send `Use $alife-worlds:commands to show the ALife Worlds command menu.`

| Find in Codex | What it does |
| --- | --- |
| `@create-world` | Create or connect a world in this Codex project. |
| `@import` | Import an agent, world or plugin into this project. |
| `@export` | Export an agent, world or plugin to reuse elsewhere. |
| `@world` | Customize your world's art, layout and behavior. |
| `@plugin` | Check plugin versions, updates, rules and workflows. |
| `@rule` | Set or view rules for the agent in this chat. |
| `@universal` | Set rules inherited by new agents and successors. |
| `@delete` | Review and clear this project's folder contents. |
| `@commands` | Show every ALife Worlds command and what it does. |

**create-world** runs the project setup flow. **rule** applies to the agent in this chat, **universal** handles incoming-agent inheritance, **world** manages the world, and **plugin** manages plugin-wide rules and workflows. These four skills also support listing and exporting rules. **export** directly prepares a portable definition or scoped rule prompt.

**import** writes only to this chat's verified project and preserves incoming agent versions and compatible local changes. Definitions transfer no private chat history, credentials or native identity. New-agent creation stays with Agent Support. **delete** shows a recovery-backed plan and requires the exact final human confirmation. Selecting a skill adds it to your draft.

The download contains the full command and integration guides. The website, Dot assets and private world data remain outside the plugin distribution.

To check your version, select **plugin** and ask which plugin version created your world and which version last ran it. Ask for updates to compare your installed plugin with the latest public release.
