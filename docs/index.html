Install ALife Worlds

Choose your app, install the plugin, and create your first world.

Set up Install Create a world

1. Set up Codex

Install the ChatGPT desktop app and sign in. Open Codex, select Local / This computer, and choose the folder where you want your world to live. If you already use Codex, open a chat in your local project.

2. Install the plugin

Paste this message into your local Codex chat.

Install ALife Worlds for Codex from this official GitHub repository.
https://github.com/ALifeWorlds/alife-worlds-releases

Check my current installation and update it if needed. Use the latest
Codex release ZIP and its SHA-256 checksum. Follow INSTALL.md to verify
and install it through Codex. Help me set up Node.js 20 or newer if needed.

Keep my projects and settings intact. Tell me when the plugin is ready.
Wait for me to ask before creating a world or any agents.

You can start in regular ChatGPT for help. Complete installation in a local Codex chat.

Windows PowerShell guide · Download the Codex ZIP (0.4.33)

3. Create a world

Type @create-world in your local Codex chat, select the ALife Worlds skill, and ask to use the bundled Anthill. You can also send this prompt.

Use $alife-worlds:create-world to set up the bundled Anthill world in this project.

To start with your own artwork, attach it in the project chat or share the path to your artwork folder.

Codex command reference

Set up Install Terminal and chat Create a world Your agents Update

1. Set up Claude Code

Install Claude Desktop and sign in with an account that has Claude Code access. Install Node.js 20 or newer, then reopen Claude.

Run the plugin in a Local session in the app’s Code tab. Regular Claude chats and Projects can help you plan your world.

2. Install the plugin

Open Claude’s Code tab and start a new Local session. Run these commands one at a time.

/plugin marketplace add ALifeWorlds/alife-worlds-releases
/plugin install alife-worlds@alife-worlds

Close and reopen Claude.

To install by upload, download the Claude ZIP (0.1.13), then select it under Customize → Plugins → Add → Upload plugin.

Claude Code plugin checksum

Terminal and chat options

Follow the Claude Code setup guide for your operating system. Install Node.js 20 or newer and reopen your terminal before running these commands.

claude plugin marketplace add ALifeWorlds/alife-worlds-releases
claude plugin install alife-worlds@alife-worlds

Open your project folder and run claude. Type /mcp to check that ALife Worlds is connected.

In a Claude Code chat, you can use the same two /plugin commands from the app steps. Start a new session afterward. You can also paste this message into a local Claude Code chat.

Install ALife Worlds for Claude Code from this official GitHub repository.
https://github.com/ALifeWorlds/alife-worlds-releases

Check my current installation and whether Node.js 20 or newer is available.
Use the terminal steps in the Claude section of the README to install
or update the plugin. Verify the result and tell me if I need a new session.
Wait for me to ask before creating a world.

3. Create a world

In Claude’s Code tab, start a new Local session. In the folder picker, choose New folder, name it Anthill, and select it. Run this command by itself to start with the bundled Anthill.

/alife-worlds:start

Open the viewer link Claude returns. This chat becomes your Director.

Director, Agent Support and World 1.0 use separate chats in the same project. If a role chat does not open automatically, start a new Local chat in that folder when Director or Agent Support asks.

For a custom world, add an idea, for example /alife-worlds:start a moonlit pine village. To add your own artwork, tell Director which files or folder to use.

Your agents

Director, World 1.0 and Agent Support are saved in your project’s alife-agents/ folder. Edit them there and start a new chat in the same folder to use your edits. Type /agents for agent help, or ask Claude to list your project’s agents.

Coming back later

Start a new Local session in the same folder to reuse your world. To make that chat your Director, run /alife-worlds:role director.

Update the plugin

In Claude’s Code tab, run /plugin marketplace update alife-worlds. Select Update now for ALife Worlds in the installed plugin list if offered. Reopen Claude and start a new chat. If you installed from a ZIP, upload the latest Claude ZIP.

From a terminal, run:

claude plugin marketplace update alife-worlds
claude plugin update alife-worlds@alife-worlds

Use /alife-worlds:commands to see the available commands.
